# Genshin Build Assistant

A RAG-powered chatbot that answers Genshin Impact character build questions — artifacts, weapons, team comps, talent priority, and materials. Data is scraped from [game8.co](https://game8.co/games/Genshin-Impact) and stays local; answers are generated by Gemini grounded strictly in retrieved context.

Built as a solo portfolio project. The engineering story is documented in [`CLAUDE.md`](CLAUDE.md).

---

## What it does

Ask natural-language questions and get grounded, cited answers:

- *"What artifacts should I use on Varka?"*
- *"Best F2P weapon for Hu Tao?"*
- *"What teams work with Neuvillette?"*
- *"What talent books does Kazuha use?"*
- *"Is Tartaglia C2 worth pulling?"*

Questions about characters not in the dataset get an explicit fallback rather than a hallucinated answer.

---

## Stack

| Layer | Technology |
|---|---|
| Scraper | `requests` + `BeautifulSoup` — game8.co, 1.5 s delay, custom User-Agent |
| Vector store | Pinecone Serverless (free tier) — server-side `llama-text-embed-v2` |
| Generation | Gemini 2.0 Flash via `google-genai` SDK |
| Cache | Redis 7 (local Docker) — SHA-256 keyed, 24 h TTL |
| API | FastAPI + Uvicorn |
| Frontend | Vanilla HTML/JS (`frontend/index.html`) — no build step |

## Setup

### Prerequisites

- Python 3.10+
- Docker Desktop
- [Gemini API key](https://aistudio.google.com/app/apikey) (free tier works)
- [Pinecone account + API key](https://app.pinecone.io) (free Starter plan)

### Install

```bash
# 1. Clone and install dependencies
pip install -r requirements.txt

# 2. Configure environment
copy .env.example .env
# Edit .env — set GEMINI_API_KEY and PINECONE_API_KEY

# 3. Start Redis
docker compose up -d
```

### Run the full pipeline

```bash
# 4. Scrape all ~120 playable characters from game8.co
#    (~3 min at 1.5 s/request; skips characters already scraped today)
py scrape.py

# Test with just 5 characters first:
py scrape.py --limit 5

# 5. Embed and upsert to Pinecone
#    (creates the index on first run; skips unchanged characters on re-runs)
py ingest.py

# Re-ingest a single character:
py ingest.py -c varka

# 6. Start the API
py serve.py
# or directly: uvicorn src.api.app:app --reload --port 8000

# 7. Open the frontend
#    Just open frontend/index.html in a browser — no build step needed.
```

## API reference

### `POST /query`

```json
// Request
{ "question": "best artifacts for Varka?" }

// Response
{
  "answer":     "According to Varka's artifacts data, his Best-in-Slot is...",
  "sources":    [{ "character": "varka", "section": "artifacts", "score": 0.91, "last_updated": "2026-08-26" }],
  "cached":     false,
  "latency_ms": 1240.3
}
```

### `GET /health`

```json
{
  "status": "ok",
  "redis":  "connected",
  "known_characters": ["albedo", "alhaitham", "..."]
}
```

### `DELETE /cache/{character_name}`

Flushes the Redis cache. Call after re-ingesting a character post-patch.

## Post-patch workflow

Genshin patches every ~6 weeks. When new character data is available on game8:

```bash
# Re-scrape the updated character(s)
py scrape.py --force       # re-scrape all
# or target one:
py scrape.py --limit 1     # only if you've updated KNOWN_CHAR_NAMES manually

# Re-ingest — change detection skips unchanged characters automatically
py ingest.py

# Flush stale cached answers
curl -X DELETE http://localhost:8000/cache/varka
```

## JSON schema

Each `character_data/*.json` has these top-level keys, which map 1-to-1 to Pinecone chunks:

| Key | Contents |
|---|---|
| `overview` | Identity, element, rarity, tier ratings, strengths/weaknesses |
| `artifacts` | Best sets (with piece counts), stat priority per slot, substat order, goal stat targets |
| `weapons` | Ranked weapons with explanations (BiS, statstick, 4-star, F2P) |
| `talents` | Priority order with rationale, all 4 passives (labeled combat/utility) |
| `teams` | Mono-element comps with member roles, flex teammates with role + explanation |
| `constellations` | C1–C6 with effects, star ratings, pull recommendation |
| `materials` | Ascension + talent items grouped by type (gem, book, boss drop, etc.) |

## Notes

**Data source:** game8.co. Scraped data is personal and non-commercial, stays local, and is synthesized by the LLM rather than republished verbatim. The scraper identifies itself with a custom User-Agent and observes a 1.5 s delay between requests.

**Embeddings:** Pinecone's integrated server-side `llama-text-embed-v2`. No vectors pass through application code.

**Known-character fallback:** The API checks whether the question names a character in the dataset before calling the LLM. Unknown characters return an explicit message rather than a hallucinated answer.

**Cache:** Answers are cached in Redis keyed by a SHA-256 hash of the normalized question. TTL is 24 h by default. Post-patch re-ingest + cache flush restores freshness.
